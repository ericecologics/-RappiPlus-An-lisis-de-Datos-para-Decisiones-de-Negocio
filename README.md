# 📊 RappiPlus – Análisis de Datos para Decisiones de Negocio

**Autor:** Eric Vázquez González  
**Objetivo:** Evaluar si el programa de suscripción **RappiPlus** incrementa la frecuencia de compra y el valor generado por usuario.

---

## 🚀 Descripción del Proyecto
Este análisis end-to-end explora el impacto de RappiPlus en el comportamiento de los clientes.  
Se aplican técnicas de **segmentación, visualización y modelado estadístico** para responder preguntas clave de negocio.

---

## 🛠️ Tecnologías Utilizadas
- Python (pandas, numpy, matplotlib, seaborn)
- Jupyter Notebook
- Exploratory Data Analysis (EDA)
- Business Intelligence mindset
